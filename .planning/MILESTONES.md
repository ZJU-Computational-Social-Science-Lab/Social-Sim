# Milestones

## v1.0 — Contagion Spread Framework

**Status:** In Progress
**Started:** 2026-03-08

**Goal:** Add a general-purpose grid-based contagion/spread model that works for both disease (SIR/SEIR) and information diffusion, using configurable rules and LLM-driven agents.

**Target features:**
- Grid-based agent positioning with adjacent visibility
- State tracking per agent (hidden from other agents)
- Movement and speak actions
- Configurable spread rules (proximity-based and action-directed)
- State decay/recovery per rule configuration
