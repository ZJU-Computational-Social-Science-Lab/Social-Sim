       - INSTRUCTION with XML format (STEP 1 ONLY - target only):
         ```
         <Action name="speak"><target>Name</target></Action>
         ```

         NOTE: Message is collected in STEP 2 via separate freetext prompt (COMM-04).

    CRITICAL: Moore neighborhood means max(dx, dy) <= 1, NOT Manhattan distance <= 1.
    Example: (5,5) to (6,6) has dx=1, dy=1 - this IS adjacent (diagonal).
