Create ContagionScene extending VillageScene with contagion state management.

1. Create `src/socialsim4/core/contagion/scene.py`:
   - File header docstring explaining ContagionScene purpose
   - Import random from stdlib
   - Import VillageScene, GameMap from village_scene
   - Import ContagionState, StateTransition from local modules
   - Import ContagionStatistics, TransitionEvent from .statistics

   Define `class ContagionScene(VillageScene)`:
   - `TYPE = "contagion_scene"`
   - `__init__(self, name: str, initial_event: str, game_map: GameMap, rules: list[StateTransition], initial_infected_count: int = 1, **kwargs)`:
     - Call super().__init__(name, initial_event, game_map, **kwargs)
     - Store rules and initial_infected_count
     - Initialize `self._statistics = ContagionStatistics()`

   - `pre_run(self, simulator: Simulator)`:
     - Call super().pre_run(simulator)
     - Get list of agents
     - Randomly select `initial_infected_count` agents
     - For each agent:
       - Set `agent.properties["contagion_state"]` to INFECTED (if selected) or SUSCEPTIBLE
       - Set `agent.properties["contagion_turns"] = 0`
     - Call `self._update_statistics(simulator)`

   - `pre_turn_rules(self, simulator: Simulator)`:
     - For each agent, increment `contagion_turns`
     - For each agent, call `self._evaluate_decay_rules(agent, simulator)`
     - Call `self._update_statistics(simulator)`

   - `_evaluate_decay_rules(self, agent, simulator)`:
     - Get current state from agent.properties["contagion_state"]
     - Get turns from agent.properties.get("contagion_turns", 0)
     - For each rule with trigger_type == "decay":
       - If rule.from_state matches current state AND turns >= rule.decay_turns:
         - Call `self._apply_transition(agent, rule, simulator)`
         - Break (only one transition per turn)

   - `_apply_transition(self, agent, rule, simulator)`:
     - Store from_state before change
     - Update `agent.properties["contagion_state"] = rule.to_state.value`
     - Reset `agent.properties["contagion_turns"] = 0`
     - Create TransitionEvent and call `self._statistics.record_transition(event)`

   - `_update_statistics(self, simulator)`:
     - Call `self._statistics.update(simulator.agents)`
     - Call `simulator.emit_event_later("contagion_stats", {...})` with:
       - counts: current state counts
       - agent_states: {agent_name: state} dict for frontend

   - `serialize_config(self)` returning rules and initial_infected_count
   - `deserialize_config(cls, config)` class method

2. Create `tests/unit/test_contagion_scene.py` with tests per behavior spec
3. Update `__init__.py` to export ContagionScene
